# 📝 Interactive To-Do List Application

A sleek, responsive, and modern To-Do List web application built using pure HTML5, CSS3, and Vanilla JavaScript. Features a dark-mode glassmorphism aesthetic, task filtering, live search, counter badges, and custom modal confirmation dialogs.

---

## 🌟 Key Features

* **CRUD Operations:** Create, read, edit, and delete tasks easily.
* **Persistent Storage:** Integrated with browser `LocalStorage` so tasks stay saved after page refresh.
* **Smart Filtering:** Quick filter buttons for **Total**, **Completed**, and **Incomplete** tasks with active status indicators.
* **Live Search:** Dynamic search input to find specific tasks instantly.
* **Custom Modals:** Custom-styled floating modal dialogs with backdrop blur overlay for task editing and clear-all confirmations.
* **Keyboard Shortcuts:** Quick action triggers like pressing `Enter` to add tasks.
* **Responsive UI:** Dark Mode theme powered by Glassmorphism styles for modern desktop and mobile viewports.

---

## 🛠️ Built With

* **HTML5:** Semantic layout structure and modal markup.
* **CSS3:** Custom Glassmorphism, Flexbox, blur overlays, CSS animations, and custom styling.
* **JavaScript (ES6+):** Dynamic DOM manipulation, state management, filtering logic, and LocalStorage integration.
